# Виджет часов для Android (стиль iOS Digital Clock «19:45»)

Этот архив содержит **всё необходимое** для установки и использования квадратного виджета часов точь-в-точь как на фото (скругленный квадрат, 60 радиальных секундных засечек по периметру с плавной индикацией секунд, крупный узкий шрифт цифр с круглым двоеточием и переход в будильник по нажатию):

---

## Способ 1. Быстрая установка готового файла без ПК (через KWGT)
В архиве (и отдельно в чате) лежит готовый файл **`iOS_Digital_Clock_1945.kwgt`**:
1. Установите из Google Play бесплатное приложение **KWGT Kustom Widget Maker**.
2. Зажмите палец на свободном месте рабочего стола Android → выберите **Виджеты** → перетащите виджет **KWGT 2x2** (или 4x4 с изменением размера до квадрата) на экран.
3. Нажмите на добавленный виджет → сверху нажмите иконку папки **Import (Импорт)** → выберите скачанный файл `iOS_Digital_Clock_1945.kwgt`.
4. Выберите импортированный виджет и нажмите иконку **Сохранить (дискета)** сверху справа. Готово!

---

## Способ 2. Автоматическая сборка установочного `.apk` в облаке (GitHub Actions — без Android Studio)
В проект уже встроен сценарий облачной сборки `.github/workflows/build-apk.yml`:
1. Создайте бесплатный репозиторий на [GitHub](https://github.com) и загрузите туда содержимое папки проекта.
2. Перейдите во вкладку **Actions** → запустите workflow **Build Android Clock Widget APK**.
3. Через 1 минуту скачайте готовый подписанный файл **`iOS-Clock-Widget-debug.apk`** в блоке **Artifacts** и установите его на телефон!

---

## Способ 3. Сборка в Android Studio на компьютере
1. Откройте папку проекта в **Android Studio** (Hedgehog / Iguana / Ladybug или новее).
2. Нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)** или запустите проект напрямую на подключенном телефоне кнопкой **Run (▶)**.
3. После установки нажмите **«Закрепить виджет на главном экране»** прямо в приложении или добавьте виджет **«Часы 19:45»** через меню виджетов рабочего стола.
